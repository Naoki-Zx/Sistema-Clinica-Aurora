# 🏥 Clínica Aurora — Sistema de Gestão e Agendamentos

> Aplicação web comercial desenvolvida para otimizar o cadastro de pacientes, agendamentos e controle de serviços em clínicas e consultórios.

---

## 📸 Demonstração do Sistema

![Demonstração da Clínica Aurora](https://naoki.free.nf/clinica-aurora)
*Interface responsiva e painel de controle do sistema.*

---

## 🚀 Funcionalidades Principais

- **Painel Principal (Dashboard):** Resumo visual com cards estatísticos e métricas do sistema.
- **Gestão de Pacientes/Clientes:** CRUD completo (Cadastro, Listagem, Edição e Remoção).
- **Agendamentos Relacionais:** Vínculo direto entre dados de clientes e serviços/médicos no banco.
- **Autenticação & Segurança:** Acesso protegido por sessão e proteção rigorosa contra SQL Injection com PDO Prepared Statements.
- **Interface Responsiva:** Layout adaptado para dispositivos móveis, tablets e desktop.

---

## 🛠️ Tecnologias Utilizadas

- **Backend:** PHP 8 (PDO)
- **Banco de Dados:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript (ES6)
- **Estilização & Responsividade:** Bootstrap 5
- **Ambiente Local:** XAMPP / Apache
